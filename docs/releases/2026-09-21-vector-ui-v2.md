# Vector UI v2 release candidate

Status: BUILT. Not deployed or visually certified. Existing live product remains on commit 338e07b24d3096d30dcc97fe14c33a03261b7e86.

## Purpose and implementation

Continue the existing application with the newer approved Vector design direction: blue Vector mark, dark navigation, compact Today view, grouped operational workspaces, a visible decision queue, scoped workforce counts, leave overview and mobile navigation. The design references are the user's September 19 Vector Factory Operations Dashboard Showcase and Directors & Ops dashboard. This release applies their presentation direction; it does not implement every illustrated manufacturing-intelligence feature or reuse their illustrative financial results.

The new navigation is derived from the current account's registered source controls. All registered destinations remain available once, including extension routes under More. An unavailable route cannot be invoked through the shell fallback. Employee home remains its existing self-service workflow. Source workflow buttons remain authoritative for navigation and all data-changing actions. Current engine, authentication, permissions, data schemas, sealed runtime, readiness flags, deployment configuration and holds are unchanged.

The new Today view prioritises people on site, reported sickness, pending leave and action-needed count. A late evidence response refreshes both the action queue and attention total. Decision reasons, freshness and required authority remain available in accessible disclosures. Awaiting-confirmation work remains passive and does not inflate the action-needed count. No forecast savings, production throughput, energy savings or AI outcomes are fabricated.

## Validation

23 focused Node tests pass: 14 existing workflow evidence tests, 4 existing action queue tests, 4 new routing tests and 1 new asynchronous count/details regression. JS syntax and the Vector source guard pass on the scoped checkout. Evidence is in docs/releases/vector-ui-v2-evidence/.

Independent review identified a stale asynchronous KPI, hidden decision detail and an unnamed mobile assistant control. All three were corrected. Navigation tests first reproduced an unsafe unavailable-route fallback and missing grouped navigation on the original code.

The old guard failed on the unchanged baseline with three stale source-string expectations: Review-only labels, counting all items rather than action-needed items, and superseded empty-state text. The updated guard requires the current source-owned action-affordance contract, filtered action count and actual empty message. It preserves evidence and scope checks. An existing VM test used deep equality on cross-realm arrays and failed despite identical IDs; converting the observed arrays into the test realm repairs that assertion without changing its expected values.

Full repository CI, the exact Docker image, browser visual checks, mobile viewport checks and deployed action-to-persisted-result proof remain incomplete. Local browser preview was refused by the Cloud Browser's file-protocol security policy; no alternate browser or policy workaround was used. Source tests are not a substitute for these missing checks.
