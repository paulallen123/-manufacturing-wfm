# VECTOR Research Alignment — 23 Sep 2026

Status: ADDITIVE IMPLEMENTATION LAYER — isolated from the Friday FORGE critical path.

## Purpose

Absorb the current manufacturing / analyst / competitor research into VECTOR without replacing any existing design, route, deterministic rule, authority boundary or working capability that already provides equal or better customer value.

The rule is simple:

> Reuse first. Extend only where there is a real gap. Never create a second product concept, second authority engine or second navigation model.

## Existing design preserved

The approved five-section experience remains:

- Today
- People
- Plan
- Factory
- Improve

No new primary navigation is introduced for AI, Digital Twin, Autopilot, Decision Receipts, Factory Playback, Country Packs, Skills Intelligence or Value Ledger. These capabilities are contextual projections over existing authoritative data and workflows.

## Research requirements absorbed

### Manufacturing Asset Intelligence

The existing Implementation Digital Twin is extended additively to represent machine, automation, material, WIP, energy, tooling, facility, inventory, supplier-capacity, cash-commitment, knowledge, work-order, order, product and quality-event nodes.

A read-only Asset Intelligence projection groups the same Twin evidence into people, machines, materials, energy, tooling, production, finance and knowledge views. It does not create another graph or source of truth.

### Decision Receipts

The existing Decision Episode and Decision Outcome Proof remain authoritative.

The new Decision Receipt is a read-only explanation projection showing:

trigger -> evidence -> options considered -> prediction -> recommendation -> authority required -> selected action -> observed outcome -> verified value proof.

It never grants execution authority and never invents savings.

### Factory Playback

The existing Decision Episode, Realtime Event Service and Outcome Proof are composed into a chronological Factory Playback.

Playback is evidence reconstruction only. It does not become a historian, MES, machine-control system or new event authority.

### Skills Intelligence

The existing Training Twin remains the learning system.

Skills Demand Intelligence compares authoritative production demand with current Training Twin competence evidence to identify verified coverage gaps and training candidates. It cannot certify competence, assign shifts or grant work authority.

### Country Policy Packs

A versioned Country Policy Pack registry provides a safe place for working-time, overtime, rest, absence, holiday, payroll, AI-governance, privacy, worker-category, retention, certification and safety requirements.

Only verified, effective packs are returned to runtime consumers. Missing coverage fails closed to authoritative legal/customer review. Country Packs never override law, payroll, safety or customer policy systems and never grant execution authority.

### Human + machine orchestration

The Digital Twin asset model can now represent people, machines and automation together for decision context.

VECTOR remains outside certified machine-control authority. It can reason, simulate and recommend against machine state; it must not directly create unsafe industrial control authority.

## Friday protection rule

This branch must not displace the Friday FORGE critical path.

The current FORGE proof blocker remains ahead of research expansion. No module in this branch is wired into strict hosted proof, production deployment or primary UI until the exact FORGE candidate is green and regression evidence is available.

## Acceptance gates

A research capability can move into FORGE only when:

1. it reuses an existing owner;
2. it is additive or demonstrably replaces something with better customer value;
3. it keeps tenant/site/legal-entity isolation;
4. it preserves deterministic business rules and authority boundaries;
5. it fails closed on stale, missing or unverified evidence;
6. it does not create unsupported ROI or compliance claims;
7. it fits Today / People / Plan / Factory / Improve;
8. it has a rollback path;
9. its tests pass independently;
10. exact-candidate hosted proof remains green after admission.
