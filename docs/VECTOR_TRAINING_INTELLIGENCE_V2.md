# VECTOR Training Intelligence V2

Status: additive build on top of the converged FORGE head. It does not replace the existing Training Twin, adaptive coach, video worker, Product Factory, Digital Twin, Autopilot or five-section VECTOR UI.

## Product principle

VECTOR should not behave like a separate LMS. Training is an embedded performance system:

real work -> detect need -> minimum useful support -> practice -> independent task -> evidence -> retention review -> next-best intervention.

Passive exposure never proves competence.

## Existing capability preserved

- Training Twin and role/competency recommendations.
- SHOW_ME / GUIDE_ME / PRACTISE / TEST_ME.
- Contextual in-product coach.
- Scenario practice.
- Version-bound workflow manifests.
- Playwright video capture.
- Captions and transcripts.
- Training artifact evidence registry.
- Change-impact regeneration planning.
- Exact-build proof and fail-closed publication rules.

## V2 additions

### Voice
A synthetic VECTOR brand voice contract binds every narration to the exact artifact fingerprint, release SHA, locale, script digest and voice profile. Human voice cloning is deliberately excluded from the base contract. Target audio is 48 kHz, -16 LUFS, with content-match, privacy and secret scans before admission.

### Media production
The media planner turns a verified SHOW_ME workflow into a 1080p scene plan with intro, real workflow steps, recap, captions and narration. Media remains guidance only.

### AI-assisted authoring
Authoring jobs accept only approved, versioned, digest-bound sources. The output contract requires an explanation, worked example, retrieval practice, realistic scenario, misconception feedback, an independent task and accessibility notes. High-risk payroll, safety, compliance, legal, access-control and production-authority content cannot auto-publish.

### Coach orchestration
The coach decides whether the user needs no interruption, a refresher, a worked example, guided practice, simulation or an independent test. Mastered users are left alone unless evidence indicates forgetting or repeated help.

### Quality gate
Training cannot become publishable simply because a video rendered successfully. Publication requires exact-build binding, source grounding, retrieval practice, independent performance, explanatory feedback, captions, transcript, narration, privacy/secret admission and—when AI tutoring is enabled—groundedness, hint-first behavior and reliable escalation.

## Target learner experience

1. User opens a normal VECTOR task.
2. The coach checks role, current workflow, competence evidence, recency and help history.
3. If no help is needed, nothing appears.
4. If help is needed, VECTOR chooses the smallest useful intervention.
5. The learner can hear the VECTOR voice, watch an exact-version demonstration, practise a safe scenario or perform the real task.
6. Only independent/observed evidence advances mastery.
7. Retention is checked later, preferably through authentic work.
8. Product changes trigger only affected training artifacts for regeneration and re-validation.

## Background training factory

Approved source registry -> authoring job -> AI draft -> quality checks -> human review where required -> workflow manifest -> media plan -> narration job -> exact UI capture -> composition -> captions/transcript -> privacy/security scan -> quality gate -> durable publication -> learner delivery -> outcome telemetry -> regeneration.
