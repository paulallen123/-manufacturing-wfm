# Autopilot permit → execute → read-back oracle — bounded handoff

- Requirement/source: issue #265 Autopilot lane requires exact-SHA permit → execute → read-back, independent verify and rollback/containment. The existing `operations/runtime/autopilot-execution-engine.cjs` exposes permit, execute and status responses and reads from the lifecycle adapter. This slice only assesses a captured successful VERIFIED path; rollback/containment and independently measured outcome remain separate gates.
- Owner/conflict: canonical release/integration owner retained. Current open PR/branch searches found no focused permit/execute/read-back capture verifier. PR #444 owns `safePlan` input-shape correction; PR #273 owns outcome learning; broad Autopilot PRs own other work. This package adds new read-only files, no runtime/validator overlap, runner, writer, controller, deployment or integration.
- Exact base: `48dce8f697825c8cd5f99b3e5aeea3953647f8c2` (`release/vector-customer-ready-candidate-20260925`). Changed files: `scripts/autopilot-readback-proof-oracle.mjs`, `tests/autopilot-readback-proof-oracle.test.mjs`, this record.
- Result: a bounded pure JSON-text oracle compares one candidate/deployment/tenant/context/episode/option across captured permit, execution, status history and independently collected lifecycle status. It requires current permit validity, exact three-state PREPARED→APPLIED→VERIFIED history including the promoted episode and selected option, consistent lifecycle event ID/employee/kind in the real `/api/workforce/lifecycle/status` `recent` array, and `outcomeStatus: UNPROVEN` with null digest. The permit actor accepts the runtime's bounded, nonempty session email value, including `m@test`; opaque runtime option, context, tenant, worker and event-key values are also accepted within their runtime bounds. The lifecycle endpoint returns only the latest 20 events; an aged-out event blocks proof and needs a fresh approved read-back route or retained authenticated capture. The oracle cannot authenticate collector custody or turn lifecycle read-back into measured benefit.

No final image, actual browser, hosted lifecycle, customer or personnel mutation test ran.
